// VehiculosExpress

Esto es una app de escritorio en c# con Spectre, la base de datos que utilzamos es SQLite.
Esto es un pequeño proyecto de prueba para la creación de un proyecto de prueba en .NET 8.0 con C# 12.0.
Donde trabajamos con ADO.NET para la conexión a base de datos y la creación de un CRUD básico para la gestión de vehículos.

Este proyecto tiene solo una entidad llamada Vehiculo, que tiene las siguientes propiedades:
- Id: int
- Marca: string
- Modelo: string
- Color: string
- Anio: int
